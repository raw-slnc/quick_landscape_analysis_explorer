# Maps4QGIS

QLAE がローカルサーバーから表示するデスクトップ地図です。Avid Maps Extra の QGIS 版として、同じ地図画面と操作を使用します。

- `index.html` はブラウザの優先言語または保存された選択に応じて、英語版か日本語版を開きます。
- 言語は Specs の「Language / 言語」で、自動・English・日本語から選び直せます。
- 解析管理から開くと、GeoPDF と DEM の読み込み操作を案内します。既存ボタンとZIP内の選択可能なファイルが順に点滅します。
- 案内画面から別の PDF や DEM も選べます。案内なしの通常デスクトップ表示もあります。
- 地図の変換と保存はブラウザ内で行います。解析ZIPから選んだファイルだけを QLAE のローカルサーバーから読み込みます。
- バックアップは大きな DEM でも扱える `.m4qbackup` 形式で書き出します。従来の `.json` バックアップも復元できます。保存先の選択はブラウザの対応状況に従います。

元の PWA の配布手順はこのフォルダには適用しません。第三者ライブラリのライセンス文は `LICENSE-*.txt` にあります。
