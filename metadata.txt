about=Quick Landscape Analysis Explorer makes hillshade, slope, CS Map, contour and catchment layers for a polygon area or the preview extent. The DEM comes from a local file or is downloaded from GSI elevation tiles (Japan), VIRTUAL SHIZUOKA (Shizuoka), Nagano Prefecture open data, AHN4 (Netherlands), IGN LiDAR HD (France), Rhineland-Palatinate and Bavaria DGM1 (Germany), LINZ (New Zealand) or AWS Terrain Tiles (global). Each analysis is saved as one portable ZIP beside the QGIS project. What the A-series preview shows can be exported as a GeoPDF with separate layers, an image or a print layout, and the analysis files as styled layers, from which a print layout can also be made later. Catchments use GRASS r.watershed where available, otherwise the plugin's own computation. English user interface with a Japanese language switch.
changelog=
    0.3.1 - Added Regional analysis for Japan: CS Valley and valley flow, with VIRTUAL SHIZUOKA, GSI DEM1A 1 m and the Nagano 0.5 m DEMs. Added a Manual button. The analysis checks are remembered, and contours come out hidden. A CRS for field maps is suggested when the preview is in Mercator. Maps4QGIS: correct 3D for Mercator maps.
    0.3.0 - [IMPORTANT] Added Maps4QGIS, a bundled desktop map for viewing GeoPDFs with DEM-based 3D terrain. From a managed analysis, QLAE can create a GeoPDF on demand, save it in the analysis ZIP and exports folder, and guide you through loading it with the DEM. Maps4QGIS can also be opened independently from the QGIS Plugins menu.
    0.2.0 - Improved analysis stability and memory efficiency with memory checks, lower-memory terrain processing, and clearer disk-full reporting. [IMPORTANT] Fixed an issue that could close QGIS when an analysis was cancelled. Network DEM tiles can now be retained and reused for offline reanalysis, and regional-source coverage is shown in previews. Added Regional analysis for the Netherlands with terrain, canopy, geomorphology, and aerial-imagery layers. Also refined GeoPDF output, analysis management, status and style handling, keyboard navigation, and regional-analysis compatibility after plugin updates, including an AHN coverage fix for southern Limburg.
    0.1.1 -[IMPORTANT] The top of the window now shows the country and region of the chosen DEM source (or, for other sources, the country at the preview centre) with the latitude and longitude of the preview centre. DEM sources are offered only near their own country, and the chosen source is cleared when the preview moves outside its area. Improved DEM fetching: an area without IGN LiDAR HD data is recognised quickly, and in Rhineland-Palatinate an older survey is used when the newest file of a tile is missing. After an analysis, a notice tells you when part of the area has no data from the chosen source. A local DEM file without a position (a DXF/DWG drawing, or a raster without georeferencing) can now be used, as a reference feature. Choosing "Local DEM file" now opens the file chooser straight away. Added a reload button for the loaded local DEM; it resets the preview's position. Improved unstable behaviour when zooming the preview in and out; zooming out is now limited. With a polygon layer as the area, a red cross appears near the centre of the preview and snaps to the centre. The plugin windows now use a fixed 9 pt font, so their layout no longer breaks with the QGIS font setting. Revised the default style of the output catchments. Catchments are now divided down to 2 ha (was 5 ha), so the terrain can be read by smaller slopes and hollows. Analyses made earlier keep their 5 ha catchments; run the analysis again to get the new ones. The analysis ZIP and the exported layers now include a DEM for use with the GeoPDF (dem_for_geopdf.tif): in the preview's CRS, uncompressed and covering the whole GeoPDF, so that apps such as Avid Maps' field map can use it together with the GeoPDF. Cells without data are filled: in Japan from GSI elevation data (the sea at 0 m), elsewhere from AWS Terrain Tiles. CRSs whose axes point south and west, such as S-JTSK / Krovak (EPSG:5513), are also supported. Analyses made earlier have none; run the analysis again to get it.
    0.1.0 - First public release.
